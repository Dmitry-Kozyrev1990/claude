# Долька — сервис для организаторов совместных закупок продуктов

Веб-приложение (PWA) для тех, кто собирает совместные закупки в чатах дома, района или родительских групп.
Раньше это делали через чат, Google-таблицу и переводы на карту. Зачем такой сервис и кто его конкуренты, описано в
[`research/food-bulk-app-market-research.md`](../research/food-bulk-app-market-research.md), раздел 9.

## Что умеет MVP

**Организатор** (`/app`):
- создаёт закупку: поставщик, стоп заказов, минимальный заказ у поставщика, оргсбор в %, реквизиты, место раздачи;
- добавляет позиции: цена за единицу, шаг заказа (1 шт, 0,5 кг) и **коробка (ряд)** — сколько единиц надо набрать целиком;
- видит заполнение коробок; если коробка не собралась, **«Обрезать до коробок»** снимает остаток с последних заказов;
- ведёт статусы: сбор → стоп → заказано → приехало → закрыта;
- вводит **факт по весу** (приехало 1,43 кг вместо 1,5): сумма участника и оргсбор пересчитываются, переплата и долг видны сразу;
- сверяет оплаты: участник жмёт «Я оплатил(а)», организатор подтверждает сумму; фильтры «Не оплатили», «Сообщили об оплате», «Не выдано»;
- отмечает выдачу на раздаче;
- выгружает в Excel (CSV) **заказ поставщику** и **лист раздачи**;
- копирует готовые **тексты для чата**: объявление, добор коробок, напоминание должникам со списком сумм, «приехало»;
- **повторяет закупку** одной кнопкой: те же поставщик и позиции, без заказов.

**Участник** (`/z/{код}`), без регистрации:
- выбирает товары с учётом шага, видит заполнение коробок и прогресс к минимальному заказу;
- получает **личную ссылку** на свой заказ и может изменить его до стопа;
- видит итог с оргсбором, реквизиты и пересчёт по факту, отмечает оплату.

**Деньги участников через сервис не проходят**: они платят организатору напрямую. Сервис не становится
платёжным агентом (161-ФЗ / 103-ФЗ) и не выбивает кассовые чеки за организатора.

## Тарифы

| Тариф | Цена | Ограничения |
|---|---|---|
| Пробный «Про» | 14 дней бесплатно после регистрации | нет |
| Бесплатный | 0 ₽ | 1 незакрытая закупка, до 15 участников |
| Про | **500 ₽/мес** или 5 000 ₽/год | нет |

Цены и лимиты задаются в `app/plans.py`. Оплата подписки сейчас в тестовом режиме (`DOLKA_PAYMENTS=demo`):
тариф включается без списания денег. Место для ЮKassa — `YooKassaProvider` в `app/billing.py`.

## Запуск

```bash
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --port 8000
# кабинет организатора: http://localhost:8000/app
pytest -q
```

Docker:

```bash
cp .env.example .env   # задайте DOLKA_SECRET (openssl rand -hex 32)
docker compose up -d --build
```

На сервере поставьте перед приложением HTTPS-прокси (Caddy или nginx) и включите `DOLKA_SECURE_COOKIES=1`.

## Устройство

- `app/purchases.py`: закупки, позиции, заказы, коробки, факт, расчёты и выгрузки. Деньги хранятся в копейках,
  количества в тысячных долях единицы, поэтому весовой товар считается без ошибок округления.
- `app/billing.py`, `app/plans.py`: пробный период, подписка, лимиты бесплатного тарифа.
- `app/auth.py`: пароли (PBKDF2) и сессии; токены сессий и личных ссылок участников хранятся только в виде хэшей.
- `app/main.py`: HTTP API. Изменяющие запросы требуют заголовок `X-Requested-With: dolka` (защита от CSRF).
- `web/`: лендинг, кабинет (`app.js`) и страница участника (`join.js`) на чистом JS, без сборки.
- База SQLite (`data/dolka.sqlite3`). Для роста перейти на PostgreSQL заменой `app/db.py`.
