# Регламент работы: агенты и недельный цикл

Цель — тратить лимит подписки только на мысль (исследование, тексты, решения), а механику отдать скриптам.

## Кто что делает

| Роль | Чем работает | Где результат | Лимит |
|---|---|---|---|
| Исследователь | навык `nova-researcher` | `weeks/<неделя>/research.md` | небольшой |
| Копирайтер | навык `nova-copywriter` | `weeks/<неделя>/posts.md` | средний |
| Дизайнер-выпускающий | навык `nova-designer` | `content/*.json` + задачи в расписании | небольшой |
| Публикация | скрипт `publish.py` по расписанию | Telegram, Instagram, отчёт в «черновиках» | минимальный |
| Синк Obsidian | ежедневная задача 21:10 | заметки `Посты/` | минимальный |
| Аналитик | навык `nova-analyst` | `weeks/<неделя>/report.md` + Obsidian | небольшой |

Всё хранится в GitHub: `Dmitry-Kozyrev1990/claude`, ветка `nova-content`, папка `nova/`. Песочница Composio временная и может стереться — в ней ничего не храним.

## Недельный цикл

**Четверг или пятница — подготовка следующей недели**
1. Новый чат в проекте «Контент-Фабрика» → «/nova-researcher неделя 13–18 октября». Агент собирает факты в `research.md`.
2. Новый чат → «/nova-copywriter напиши посты недели по research.md». Ты выбираешь хуки и утверждаешь тексты.
3. Новый чат → «/nova-designer сделай карточки недели». Получаешь страницу предпросмотра, говоришь «да» — агент сам заливает в GitHub, делает тест в «черновики» и ставит публикации в расписание.

**Каждый день в 19:30** — посты выходят сами. Отчёт приходит сообщением в канал «Нова — черновики». В 21:10 обновляются заметки в Obsidian.

**Воскресенье вечером**
4. Новый чат → «/nova-analyst итоги недели». Отчёт в GitHub и Obsidian, рекомендации на следующую неделю.

## Правила экономии
- Один чат = одна задача. Не продолжать старые длинные чаты.
- Не просить «перешли файл сюда» — файлы ходят только через GitHub.
- Запланированные задачи — только отдельные запуски, не привязанные к чату.
- В чатах проекта отключить ненужные подключения (Figma, Canva, Gmail, Календарь, Drive), если они не нужны в работе.
- Большие исследования с субагентами — только по явной просьбе.

## Если что-то сломалось
- Пост не вышел — в «черновиках» будет строка FAIL. Новый чат: «/nova-designer перезапусти публикацию за ДАТУ».
- Песочница стёрлась — ничего страшного, скрипт сам всё скачивает из GitHub и ставит браузер (~1–2 мин).
