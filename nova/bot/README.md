# Нова: бот курсов по ИИ для детей

Telegram-бот на Cloudflare Workers (бесплатный тариф). Всё происходит внутри бота:
выбор возраста ребёнка, подарок-гайд, каталог из 5 курсов и пакета, оплата
переводом на карту Озон Банка с ручным подтверждением, встречи курса с
прогрессом, прогрев и напоминания. Для владельца есть админ-панель.

## Как работает оплата

1. Покупатель жмёт «Купить», бот создаёт заказ и показывает номер карты, сумму
   и номер заказа для комментария к переводу.
2. После перевода покупатель жмёт «Перевод сделан» и присылает скриншот, файл
   или текст.
3. Админу приходит чек с кнопками **✅ Подтвердить** / **❌ Отклонить**.
4. После подтверждения курс сразу открывается у покупателя в «Мои курсы».
   Двойное нажатие ничего не ломает: решение принимается один раз.

Если заказ не оплачен через час, бот один раз напомнит.

## Админ-панель

`/admin` (отвечает только id из `ADMIN_IDS`):
- **На проверке**: все присланные чеки с кнопками решения;
- **Статистика**: пользователи, оплаты, выручка, конверсия, возраст детей, источники;
- **Последние заказы**: 10 последних со статусами;
- `/grant <id> <курс>`: выдать курс вручную (подарок, оплата другим способом).
  Коды курсов: `hello`, `learn`, `safe`, `study`, `project`, `all` (пакет).

## Где что править

- `src/content.ts`: курсы, цены, тексты встреч, прогрев, вопросы-ответы, ссылка на гайд.
  Текст одной встречи должен укладываться в 4096 знаков (лимит Telegram).
- `src/bot.ts`: сценарии бота и админ-панель.
- `src/db.ts`, `schema.sql`: база D1.

## Запуск (один раз)

1. Создайте бота в @BotFather, получите токен. Свой Telegram id узнайте у @userinfobot.
2. Зарегистрируйтесь в Cloudflare (бесплатно), затем в папке `nova/bot`:
   ```
   npm install
   npx wrangler login
   npx wrangler d1 create nova-bot      # id вставьте в wrangler.toml
   npm run db:init
   ```
3. Впишите в `wrangler.toml` `BOT_USERNAME` и `SUPPORT_USERNAME`.
4. Секреты (вводятся в терминале и в репозиторий не попадают):
   ```
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET
   npx wrangler secret put ADMIN_IDS
   npx wrangler secret put CARD_NUMBER
   npx wrangler secret put CARD_HOLDER
   npm run deploy
   ```
5. Подключите вебхук Telegram (адрес Worker выведет `deploy`):
   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<worker>.workers.dev/tg/<WEBHOOK_SECRET>`

## Проверка

`npm test` прогоняет сценарии на локальной базе с поддельным Telegram:
покупка, чек, подтверждение и отклонение, встречи по порядку, пакет,
ручная выдача, админ-панель, прогрев и напоминания.

## Автодеплой из GitHub

Добавьте в Settings → Secrets репозитория `CLOUDFLARE_API_TOKEN` и
`CLOUDFLARE_ACCOUNT_ID`. Дальше каждый пуш в ветку по умолчанию, затрагивающий
`nova/bot/`, проверяет и деплоит бота (`.github/workflows/deploy-bot.yml`).
