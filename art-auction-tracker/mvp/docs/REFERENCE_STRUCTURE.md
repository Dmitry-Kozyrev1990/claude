# Структура по образцу ценовых баз

Artprice, Artsy Price Database и MutualArt используются **только как образец структуры**:
какие разделы, сущности и поля нужны продукту. Данные из них не копируются: сбор идёт
из открытых источников (`python -m arttracker.collect status` — реестр с юридическим статусом).

Описание ниже собрано по публичным страницам и общеизвестным функциям этих сервисов.
Поля из личного кабинета подписки стоит сверить по скриншотам и дополнить таблицы.

## Разделы продукта

| Раздел у ценовых баз | Что содержит | Таблицы (`schema.sql`) | В MVP |
|---|---|---|---|
| Карточка художника | имя и варианты написания, годы жизни, национальность, ID в справочниках | `artists`, `artist_names`, `artist_external_ids` | есть; имена дополняются из Wikidata |
| Результаты торгов | список лотов художника с фильтрами | `lots`, `sales`, `auction_houses` | есть |
| Фильтры результатов | техника, размер (малый/средний/большой), дата продажи, цена, дом, страна, продан/не продан | индексы на `lots`, поле `size_class` | частично: таблица без фильтров |
| Карточка лота | название, дата создания, техника, размеры, тираж, эстимейт, цена молотка и с премией, валюта, дом, город, дата, номер лота, изображение, провенанс, литература | `lots`, `lot_images` | есть, кроме провенанса и литературы |
| Индекс цен художника | динамика к базовому году | `mv_artist_index` | есть, с 90% интервалом |
| Статистика художника | оборот и число лотов по годам, доля непроданных, распределение по технике, странам, ценовым сегментам, точность эстимейтов | `mv_artist_yearly`, `mv_artist_breakdown` | частично: оборот, доля продаж, BIAS |
| Рейтинги | художники по обороту, росту, числу лотов; топ-лоты года | `mv_artist_ranking`, `mv_top_lots` | частично: сортируемая таблица |
| Календарь торгов | предстоящие аукционы и лоты | `sales` со статусом upcoming | есть: список лотов |
| Избранное и уведомления | отслеживание художников и работ, оповещения о новых лотах и результатах | `watchlist_items`, `alerts`, `notifications` | есть: правила и лента |
| Оценка работы | ориентир цены по аналогам | `valuations` | есть |
| Отчёты о рынке | годовые и квартальные обзоры | строятся из витрин | нет |

## Чем отличаемся (это стоит говорить инвестору)

- **Экземпляр как сущность.** У ценовых баз основная единица — лот. У нас лоты связаны
  в работу → вариант (состояние доски, тираж) → физический экземпляр. Отсюда индексы по
  повторным продажам и доходность владения конкретным листом.
- **Справедливая цена с аналогами**, а не только список прошлых результатов.
- **Сигнал по предстоящим лотам**: эстимейт ниже или выше рынка.

## Источники данных по разделам

| Данные | Источник | Статус |
|---|---|---|
| Художники, имена на языках, годы жизни, ID ULAN | Wikidata (CC0), Getty ULAN (ODC-By) | одобрено |
| Эталонные карточки работ и изображения | Art Institute of Chicago API (CC0), The Met Open Access (CC0) | одобрено |
| Курсы валют | ECB Data Portal | одобрено |
| Результаты торгов | сайты аукционных домов и площадок | по одному после проверки условий: `config/approved_auction_sources.json` |
| Результаты торгов | Artsy, MutualArt | ждут проверки условий или разрешения |
| Результаты торгов | Artprice | не подключается: платная база |
