# Как выложить Lotline на сервер

Итог: сайт на вашем домене с HTTPS, регистрацией, личным кабинетом и подписками. Оплата
пока в тестовом режиме: подписка оформляется без списания денег. ЮKassa подключается
позже без переделки сайта.

На всё уходит около 30 минут.

## 1. Что понадобится

- **Сервер (VPS)** с Ubuntu 22.04 или 24.04: 2 ядра, 2 ГБ памяти, 20 ГБ диска. Подойдёт любой
  российский облачный провайдер.
- **Домен**, например `lotline.ru`. В настройках DNS у регистратора создайте A-запись: имя
  `@` (или поддомен, например `demo`), значение — IP-адрес сервера. Запись начинает работать
  в течение 5–60 минут.
- Без домена можно запустить по IP-адресу, но без HTTPS (шаг 4, вариант «без домена»).

## 2. Подключиться к серверу и установить Docker

На своём компьютере откройте терминал (в Windows — PowerShell) и подключитесь:

```bash
ssh root@IP_СЕРВЕРА
```

Установите Docker одной командой:

```bash
curl -fsSL https://get.docker.com | sh
```

## 3. Скачать проект

```bash
git clone https://github.com/Dmitry-Kozyrev1990/claude.git lotline
cd lotline
git checkout claude/dazzling-ride-ehtv40   # пока изменения не влиты в основную ветку
cd art-auction-tracker/mvp
```

Если репозиторий закрытый, Git попросит логин и токен GitHub (Settings → Developer settings →
Personal access tokens).

## 4. Настроить

```bash
cp .env.example .env
openssl rand -hex 32        # скопируйте получившуюся строку
nano .env
```

Заполните в `.env`:

| Параметр | Что вписать |
|---|---|
| `DOMAIN` | ваш домен, например `lotline.ru` |
| `LOTLINE_SECRET` | строку из `openssl rand -hex 32` |
| `LOTLINE_ADMIN_EMAILS` | вашу почту — с ней вы будете администратором |
| `LOTLINE_PUBLIC_URL` | `https://` + ваш домен |
| `LOTLINE_PAYMENTS` | `demo` — подписка оформляется без оплаты (для показа) |

Сохранить в nano: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

**Вариант без домена:** `DOMAIN=:80`, `LOTLINE_SECURE_COOKIES=0`,
`LOTLINE_PUBLIC_URL=http://IP_СЕРВЕРА`.

## 5. Запустить

```bash
docker compose up -d --build
```

Первый запуск занимает 2–4 минуты: собирается образ и рассчитываются демо-данные. Проверка:

```bash
docker compose ps            # оба сервиса в состоянии running / healthy
docker compose logs -f app   # журнал сервера, выход — Ctrl+C
```

Откройте `https://ваш-домен`. Сертификат HTTPS выпускается автоматически при первом
обращении (до минуты).

## 6. Первые шаги на сайте

1. Нажмите «Войти» → зарегистрируйтесь с почтой из `LOTLINE_ADMIN_EMAILS`. Над страницами
   появится ссылка «Администрирование».
2. В разделе «Администрирование» можно выдать тариф любому зарегистрированному
   пользователю, например инвестору, на нужное число дней.
3. Или из командной строки сервера:
   ```bash
   docker compose exec app python -m app.manage grant investor@mail.ru collector 30
   ```

## Сценарий показа инвестору

1. Откройте сайт без входа: рынок, индексы, рейтинг доступны бесплатно; цены последних
   12 месяцев, оценка и аналитика скрыты.
2. Зарегистрируйтесь → «Кабинет» → добавьте 2–3 работы: видна стоимость коллекции, а
   доходность, ликвидность и сигналы закрыты.
3. «Тарифы» → «Оформить» (тестовая оплата) → кабинет открывается полностью: прибыль,
   доходность против индекса, страховая стоимость, динамика по годам, сигналы.
4. «Как это работает» — технология: сопоставление лотов разных домов и рынков.

## Обслуживание

| Задача | Команда |
|---|---|
| Обновить сайт после изменений в репозитории | `git pull && docker compose up -d --build` |
| Резервная копия базы пользователей | `docker compose exec app python -m app.manage backup` |
| Список пользователей | `docker compose exec app python -m app.manage users` |
| Перезапуск | `docker compose restart` |
| Остановить | `docker compose down` (данные сохраняются) |

База пользователей и подписок хранится в томе Docker `lotline-data` и не теряется при
обновлении. Копии из `backup` лежат там же; забрать на свой компьютер:
`docker compose cp app:/data/ ./lotline-backup/`.

## Подключение ЮKassa (следующий шаг)

Что уже готово в коде:

- тарифы и цены — `app/plans.py`;
- таблица платежей и продление подписки после оплаты — `app/billing.py`;
- место для провайдера `YooKassaProvider` и адрес уведомлений
  `/api/payments/webhook/yookassa`;
- переменные `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` в `.env`.

Что понадобится от вас: магазин в ЮKassa (договор, shopId и секретный ключ), включённые
чеки по 54-ФЗ, публичная оферта и политика обработки персональных данных на сайте. После
подключения в `.env` меняется `LOTLINE_PAYMENTS=yookassa`.

## Вариант без Docker

Если Docker использовать нельзя: Python 3.12, виртуальное окружение,
`pip install -r requirements.txt`, `python -m arttracker.build`, затем systemd-сервис из
`deploy/lotline.service` и nginx или Caddy перед ним для HTTPS.
