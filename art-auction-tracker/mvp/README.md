# Lotline — MVP аналитики аукционных цен на тиражную графику

Рабочий прототип по плану из [`../PLAN.md`](../PLAN.md): конвейер на Python
(нормализация → сопоставление → аналитика → уведомления) и веб-кабинет, в который
встроены результаты конвейера.

> **Данные синтетические.** Художники и названия работ реальные; торги, лоты, цены и
> «фотографии» создаёт генератор `arttracker/generate.py`. Это нужно, чтобы показать
> механику без нарушения условий использования сайтов аукционных домов. Курсы валют и
> ставки премий приближённые.

## Запуск

```bash
pip install -r requirements.txt
python -m arttracker.build     # генерирует данные, прогоняет конвейер, собирает web/index.html
python -m pytest -q            # 22 теста
```

`web/index.html` — самодостаточная страница: данные внутри, открывается в браузере без сервера.

## Что внутри

| Модуль | Что делает |
|---|---|
| `arttracker/generate.py` | Синтетические лоты 2015–2026 из 7 домов в их «родных» форматах: английский и немецкий, фунты, евро и доллары, цена с премией или только молоток, размеры в мм, см или дюймах. 12 художников, 32 работы, состояния доски и тиражи, повторные продажи, копии «после», плохие фото, пропущенные размеры. Эталонная разметка — отдельно, в `truth.jsonl` |
| `arttracker/normalize.py` | Разбор автора и квалификатора атрибуции, дат, размеров, эстимейтов, цен, состояния доски, номера в каталоге-резоне и номера в тираже; перевод в доллары и разделение цены молотка и премии |
| `arttracker/matching.py` | Сопоставление на трёх уровнях (работа → вариант → экземпляр): блокировка, признаки пары, вероятность совпадения, кластеризация с ограничениями, определение состояния по изображению, очередь ручной проверки, оценка точности по эталону |
| `arttracker/analytics.py` | Индекс цен (регрессия с эффектами экземпляра и 90% интервалом), CAGR, доходность повторных продаж, ликвидность, смещение к эстимейту (BIAS), справедливая стоимость по аналогам |
| `arttracker/alerts.py` | Сверка предстоящих лотов с коллекцией и избранным, тексты уведомлений для Telegram, сигнал «эстимейт ниже/выше рынка» |
| `arttracker/build.py` | Полный прогон и сборка `web/index.html` из `web/template.html` |

## Результаты на демо-данных

- 1 887 лотов, 7 источников, 1 520 продаж, 33 предстоящих лота.
- 32 работы, 38 вариантов, 452 экземпляра, из них 367 перепродавались.
- Блокировка сокращает число сравниваемых пар на 93%.
- Качество сопоставления (F1 по парам): работа 1,00, вариант 1,00, экземпляр 0,95.
  Это верхняя граница на чистых синтетических данных. На реальных каталогах качество
  будет ниже; чтобы измерить его, нужна экспертная разметка нескольких тысяч пар.
- Восстановленные индексы художников близки к заложенным в генератор (средняя ошибка около 8%).

## Сценарий показа инвестору (5–7 минут)

1. **«Рынок»** — проблема и масштаб: индексы по сегментам, рейтинг художников по росту,
   ликвидности и доле продаж выше эстимейта.
2. **«Художники» → Бэнкси** — пузырь 2021 года и падение видны в индексе; доля лотов
   выше эстимейта и ликвидность.
3. **«Работа»** — ключевая технология: одна работа под разными названиями на трёх языках
   сведена в одну карточку; история продаж; повторные продажи одного экземпляра.
4. **«Оценка»** — продукт для коллекционера и банка: справедливая цена с диапазоном и
   аналогами, поправка на сохранность.
5. **«Уведомления»** — удержание: лента Telegram о похожих работах на ближайших торгах,
   сигнал «эстимейт ниже рынка». Отметьте художника, и лента обновится.
6. **«Как это работает»** — доказательство: тот же оттиск в каталогах четырёх домов, поля
   после нормализации, метрики сопоставления, очередь проверки, проверка индекса против
   заложенного.
